# 导视内容编辑器使用说明

这个工具供工作人员填写导视内容，使用中文表单修改标题、楼层、房间、简介和活动。无需编辑 JSON、字模文件或 FPGA 代码，也无需安装 Python。

## 打开程序

双击 `release/content_editor/GuideContentEditor/GuideContentEditor.exe`。

请保留整个 `GuideContentEditor` 文件夹。旁边的 `_internal` 目录包含运行依赖，不能删掉或只把 EXE 单独拿走。程序可以离线使用；使用 Windows 自带的微软雅黑生成字模，不随工具分发 Windows 字体。

程序优先载入同一工程的 `config/runtime_site.json`；单独分发便携文件夹时，使用包内样例。也可以用“打开”选择此前保存的草稿。每次开始工作前，先核对标题、楼层和图片配置是否属于当前展点。

## 日常操作

1. 打开对应草稿，填写页面标题。
2. 选择楼层和房间，在中文表单中修改名称、房间简介及今日活动。
3. 查看字数、排版和整套配置的字模使用提示。发现超限时，调整文字后再导出。
4. 点击“保存草稿”，将内容保存到电脑。草稿用于下次继续编辑，不是开发板直接读取的文件。
5. 点击“导出到文件…”，选择电脑上的保存位置，保留文件名 `SITE.CFG`。工具自动分配字符编号、生成字模并校验配置。
6. 将导出的 `SITE.CFG` 复制到 SD 卡根目录，替换同名文件；保留原有 BMP 和音频。安全弹出读卡器后，开发板断电插卡，再重新上电。

保存草稿不会自动更新 SD 卡，导出也不会自动更换开发板位流。首次使用动态文字功能时，需要配套的动态文字位流；原来的 V5 位流不适用 V6 配置。以后仅修改文字，无需重新编译 FPGA。

## 输入范围

| 内容 | 限制 |
|---|---|
| 页面标题、楼层名、房间名 | 每项最多 8 个字符 |
| 每段房间简介、今日活动 | 每行最多 12 个字符，共 4 行；手动换行也占行数 |
| 名称类字库 | 整套配置最多 121 种动态字符，另可复用固定界面字 |
| 简介及活动字库 | 整套配置最多 85 种动态字符，另可复用固定界面字 |

字模容量统计的是不同字符，同一字库里的重复字符不重复占槽。名称和说明使用不同大小的字库，不能互相借用容量。标点和空格也影响排版，电脑字体不支持的字符会在导出时明确提示。

修改表单文字不会自动改变 BMP 照片上的文字。图片内容仍由对应图片文件决定。

## 交付与验证

这是电脑端离线配置工具。导出成功表示配置和字模通过软件校验，不表示开发板已经完成实物验证。更换配置后，应检查标题、楼层切换、房间名称和详情内容是否与表单一致。

开发者重新打包时，在 Windows 使用带 Pillow、fontTools 和 PyInstaller 的 Python 运行 `python tools/build_content_editor.py`。构建日志和文件校验记录保存在 `reports/content_editor/pyinstaller`；该操作不修改 RTL，也不会向 SD 卡写入文件。
