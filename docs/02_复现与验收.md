# 复现与验收

## 准备文件与工具

直接上板需要 HX4S20C、供电和 USB-JTAG 数据线、HDMI 显示设备、TF 卡与读卡器，以及安路下载工具／驱动。外接五向按键为可选项，板载按键提供同样的操作。

从 GitHub 克隆或完整解压本目录后，可先运行 `python tools/reproduce.py check`。该命令检查交付文件哈希、TD 引用、配置校验和、图片索引、观察点坐标以及音频格式。

卡上要求 FAT32，而非 exFAT。工程支持从扇区 0 或 MBR 中识别 FAT32，按根目录的 8.3 短文件名查找文件。将 `TF_CARD` 内 79 个文件直接复制到卡根目录；现成的配置和素材已经配对，初次复现直接复制即可。复制后可逐文件对照 `release/reproduction_manifest.json` 中的 TF 卡清单和 SHA-256。

## 上电与下载

1. 断电接好 HDMI A、按键和 TF 卡，连接电脑与 USB-JTAG，再按开发板正常方式供电。
2. 打开安路下载工具，识别 USB-JTAG 和 EG4S20 器件。
3. 选择 FPGA JTAG 配置／下载，文件为 `release/image_nav_carousel_native_fade_seed61_untested.bit`，执行下载并检查工具提示成功。此处是加载 FPGA 配置，断电后若未另行烧录配置存储器，需要再次下载。
4. 显示输出为 800×600、约 60.32 Hz。启动时先读取配置和初始图片，配置尚未装入期间可出现有 HDMI 信号的黑画面；不要在该阶段连续发送操作。
5. 先将SW2置0。初始进入索引页的页面选择状态，没有房间框选。按上进入房间选择后，按键说明中的选择与详情操作开始生效。

先在索引页拨动SW2，检查640×480原尺寸轮播、紧贴图片底部的进度条，以及内容淡出后换布局再淡入。顶栏和底部页面选项应保持可见。将SW2置0后继续下面的房间与地图检查。

## 演示检查顺序

| 步骤 | 操作 | 应观察到的表现 |
|---|---|---|
| 1 | 上键进入房间选择，下键循环选择 | 名称与选框变化，超过当前可见行时列表滚动 |
| 2 | 对选中房间长按下 | 占用标识改变，计时随状态更新 |
| 3 | 确认打开详情，再次确认 | 对应照片及说明出现；完整照片从原界面淡入，四周保留界面 |
| 4 | 返回两次 | 先淡出大图回到详情，再关闭详情 |
| 5 | 索引页短按左，随后长按左 | 手动切换宣传图；自动轮播可开启／关闭，滑动具有缓动 |
| 6 | 在房间选择中按右 | 地图进入后选中对应观察点 |
| 7 | 返回至地图页面选择，上键进入楼层选择 | 预选当前楼层，再按上循环预选，确认后切换地图 |
| 8 | 楼层选择中按左，再按右 | 进入观察点选择并依次切点，地图位置跟随选择 |
| 9 | 长按右，长按左，再短按方向键 | 切换缩放、进入平移；标记随地图移动，最近观察点自动选中 |
| 10 | 进入参数面板，按确认切换采样 | 在同一地图区域对比最近邻与双线性缩放效果 |
| 11 | 调整亮度、音量，开启音乐与频谱 | 画面亮度和声音变化，频谱随声音更新；退出面板后继续显示 |

本套配置为 3 层、每层 10 个房间及观察点，轮播列表有 5 张图，默认周期档位为 2 秒。周期表示播放计时目标；目标图片未准备完成时会等待加载，完整切换还包含动画过程。

## 常见现象

| 现象 | 检查内容 |
|---|---|
| 显示器提示无信号 | 确认接 HDMI A、下载工具提示成功、板卡已供电，显示器支持 800×600 |
| 有 HDMI 信号但长时间没有界面 | 核对 TF 卡为 FAT32、`SITE.CFG` 位于根目录且为 27648 字节；先做文件核验，再断电重插卡 |
| 有初始图，但后续图片读不出或界面迟迟不响应 | 核对全部卡文件和接触情况。既往曾出现重插 TF 卡后恢复的现象；不能只凭该现象判断为按键或时序故障 |
| 板载操作正常，外接按键无效 | 按接线表核对 J2 针号、COM 接地及各信号对应关系 |
| 按确认似乎无效 | 页面选择状态先进入房间／观察点选择；完整大图需要详情面板展开完成后再次确认 |
| 没有声音 | 背景音乐默认关闭，先在参数面板开启；检查音量及显示设备是否支持 HDMI 音频 |
| 看到“地图加载中”或短暂等待 | 首次或未命中缓存时需要从 TF 卡加载；连续快速操作可能赶在预加载完成之前 |

详细按键见 [接线与按键](01_接线与按键.md)，版本验证范围见 [版本与验证](04_版本与验证.md)。
