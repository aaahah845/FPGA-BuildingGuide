# 编译与配置

## 环境

| 用途 | 工具 |
|---|---|
| 直接下载现有位流 | 安路 FPGA 下载工具、HX4S20C USB-JTAG 驱动 |
| 编译 RTL | Windows，Tang Dynasty 6.2.168116，EG4S20 器件支持 |
| 文件检查 | Python 3.10 及以上，仅使用标准库 |
| 配置与字模生成 | Python＋Pillow＋fontTools；复核环境为 Python 3.12.14、Pillow 12.3.0、fontTools 4.67.0 |
| 图形内容编辑器 | 上述 Python 环境，另需 tkinter；Windows 官方 Python 安装包通常包含它 |
| 缓存回归仿真 | ModelSim／Questa，复核使用 ModelSim-Altera 10.3c（Quartus 14.1 配套） |

TD、下载驱动、仿真器及系统字体由相应供应方提供，在本机安装后使用。Windows 配置导出默认使用微软雅黑 `msyhbd.ttc` 和 `msyh.ttc`；交付的 `SITE.CFG` 已含所需字模，直接演示不依赖电脑字体。不同字体版本可能改变重新生成的字模像素，保持原演示外观时使用交付文件。

## GUI 编译

1. 完整克隆／解压目录，建议使用较短路径，例如 `D:/FPGA/BuildingGuide`。
2. 在 TD 中打开 `src/td_project/image_multiview_gui.al`，检查器件为 EG4S20BG256，顶层为 `top`。
3. 选择 `syn_1`，执行综合至 Optimize Gate；再选择 `phy_seed61` 执行布局布线及 Bitgen。
4. 常规 GUI 构建位流在 `src/td_project/image_multiview_gui_Runs/phy_seed61/image_multiview_gui.bit`。下载新位流后，使用同一份 `TF_CARD` 内容复测。

全部 HDL、IP 配置、加密 IP、引脚和时序约束均已包含。导入完整工程时无需手工重新创建 FIFO、PLL、SDRAM 或 HDMI IP。保留原工程策略与种子，以便和已交付资源／时序报告对照。

## 独立构建入口

在仓库根目录运行；安装路径不同只修改参数：

```powershell
python tools/reproduce.py td-check --td-root "D:/anlu"
python tools/reproduce.py build --td-root "D:/anlu"
```

`td-check` 在副本中检查工程能否打开。`build` 复制 `src` 后，使用 TD 从原工程导出 `syn_1` 和 `phy_seed61` 的流程脚本，再顺序运行；所有数据库、日志和新位流位于 `.repro_work/build_日期时间/`，完成后打印结果路径。它直接执行导出的流程，避免 TD 6.2 命令行自动启动文件中出现重复的可执行文件名。

独立入口将两阶段的输出放在同一个复制后的工程目录，物理阶段从 `opt_place` 开始，读取该目录中的综合数据库。所选策略、种子、RTL 和约束仍取自 `.al` 工程。重新构建的位流用于另行验收；`release` 内保留已经上板的原发布文件。

## 内容与素材

```powershell
python -m pip install -r scripts/requirements_reproduction.txt
python scripts/site_content_editor.py
```

中文表单编辑 `config/runtime_site.json` 所表示的标题、楼层、房间、简介与活动。导出后，将新 `SITE.CFG` 放到卡根目录。命令行等效操作为：

```powershell
python scripts/export_site_cfg.py
```

输出为 `config/sd_card/SITE.CFG`。本次交付还保留同一文件在 `TF_CARD/SITE.CFG`，可用下述命令验证草稿、脚本和当前字体能否重新生成相同内容；检查结果写到工作目录，不覆盖卡文件：

```powershell
python tools/reproduce.py export-check
```

图片索引由 JSON 的 `images` 数组定义。`map_image` 关联楼层地图，`photo_image` 关联房间照片，`point_photo_image` 关联观察点照片，`point` 是该层原图像素坐标，原点在左上。文件名使用 8.3 格式，配套图片均为 24 位未压缩 BMP。替换同名文件可以更换对应图像；改变地图尺寸或布局时，应同时调整观察点坐标。

| 图片 | 本次尺寸 |
|---|---|
| `MAP1.BMP` | 960×563 |
| `MAP2.BMP` | 640×480 |
| `MAP3.BMP` | 966×600 |
| 房间、观察点和轮播图片 | 640×480 |

音频为固定 44 字节头的 PCM WAV，48 kHz、16 位、单声道。`MUSIC.WAV` 是背景音乐，`FLOOR1.WAV`～`FLOOR3.WAV` 为楼层提示，`UI1.WAV`～`UI3.WAV` 为操作提示。文件名与格式需要保持。

## 仿真与开发脚本

独立缓存回归只使用本仓库的资源管理器和测试台，无需另一个旧工程：

```powershell
python tools/reproduce.py cache-test --vsim "C:/altera/14.1/modelsim_ase/win32aloem/vsim.exe"
```

模型预置缓存元数据，检查分配、保护、尾槽归属等行为，结果应包含 `cases=268`、`checks=1618`。它不模拟板上的电气条件。

`tools` 内其余脚本保留为开发过程源码。其中 `run_*_test.py`、`package_*` 等部分工具用于历史版本对照，含原工作机路径或兄弟工程引用；首次复现使用本页列出的 `reproduce.py` 入口。`sim` 中保留完整测试台，进一步运行其他历史对照回归时，应按相应脚本准备参考版本和仿真库。
