# SITE.CFG V6 动态字模协议

文件固定为 27,648 字节，共 54 个 512 字节扇区。原 V5 的 8 KB 配置布局保持位置不变，版本号改为 6。文件同时包含配置与完整字模，加载并校验完成后才能置位 `config_ready`。启动失败不得提交部分配置。

| 位置 | 含义 |
| --- | --- |
| 0..3 | ASCII `SGC1` |
| 4 | `6` |
| 16..19 | 原名称字表 CRC32，固定界面 ABI 标识 |
| 20..23 | 原说明字表 CRC32，固定标签 ABI 标识 |
| 24..25 | 8192..27647 所有字节之和低 16 位，小端 |
| 26 | 字模载荷格式 `1` |
| 1288..1295 | 可选标题的 8 个 7 位字模编号，0 补空白 |
| 1296 | 标题标志 `0x54`；0 使用默认标题 |
| 8190..8191 | 0..8189 所有字节之和低 16 位，小端 |
| 8192..24575 | 4096 个 18 位字模存储字，各占 4 字节小端，高 14 位为 0 |
| 24576..27647 | 1536 个 16 位说明字模存储字，各占 2 字节小端 |

CRC32 字段保留原值，表示固定界面编号约定，不再表示动态输入字符集合。实际载荷由额外校验和检查。加法校验用于发现常见传输/文件损坏，不是密码学完整性保证。

大字库先存 2048 个 `even_words`，后存 2048 个 `odd_words`。每个字模 24 行，每行 24 位，行 0 放在 576 位拼接数据的最低位，每 18 位分割为一字；偶数字和奇数字分别放两库，每个库每字模占 16 个存储字。像素最高位对应字内最左列。固定编号为 0、29、30、56、57、58、59，保留原始位图；其余编号按配置中的首次出现次序分配。

说明字库按 `bank0`、`bank1`、`bank2` 顺序存储，每库 512 行。每字模 16 行，编号乘 16 即首行地址。编号 0 与 19..28 为固定空白/说明标题字，其余分配给说明和活动文本。每次导出把未使用字模写为 0，避免 warm reset 后留下旧配置字形。

板端可直接用 SD 时钟域的字模写使能写入已有双口 BRAM，视频域读端保持原先单拍读取。载荷地址 0..4095 对应大字库，4096..5631 对应说明字库。必须限制原 8 KB 配置 RAM 的写地址范围，不能让后续字模数据回卷覆盖图片文件名等配置。

开发验证命令：`python tools/test_dynamic_export.py`。开发者如确实更换固定 UI 编号或原始字模，可使用 `tools/prepare_dynamic_font_assets.py` 重新制作快照；该脚本也会重写校园示例，普通配置用户不应运行。
