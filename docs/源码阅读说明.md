# 源码阅读说明

工程入口为 `src/td_project/image_multiview_gui.al`。顶层模块 `top` 位于 `src/user_source/hdl_source/top_tf_hdmi_audio.v`，下表路径均相对此 HDL 目录。

## 从顶层找到功能

| 阅读入口 | 负责的工作 | 重点看哪些交接 |
|---|---|---|
| `top_tf_hdmi_audio.v` | 连接时钟、交互、资源、像素和音频链路 | 时钟域、请求邮箱、视频流水线顺序 |
| `guide_scene_control.v` | 将按键转换为页面、选择和操作请求 | 方向键事件、交互状态、地图进入等待 |
| `site_scene_broker.v` | 安排加载、预取及逐帧显示提交 | `wanted_key`、`request_key`、`committed_key`，请求与裁决 |
| `SD/sd_site_assets.v` | 读取配置，查找图片，分配并保护六个槽 | `valid`、`footprint`、`held`，加载完成与读端接管 |
| `SD/frame_read_write.v` | 连接两侧 FIFO、写控制器和读控制器 | 写 FIFO 跨 SD/内存域，读 FIFO 跨内存/视频域 |
| `SD/frame_fifo_write.v` | 将 BMP 像素按行和槽地址写入 SDRAM | 请求应答、FIFO 数据门限、末段收尾 |
| `SD/scene_frame_reader.v` | 根据场景和视野读取图片，生成屏幕像素顺序 | 帧描述、分段读请求、`rd_valid`、FIFO 余量 |
| `SD/bilinear_span_cache.v` | 缓存源像素并完成采样 | 两行插值、样本有效标志、大图过渡暂存 |
| `guide_scene_compositor.v` | 在基础像素上合成文字、观察点、面板与大图 | 坐标和区域命中、字模请求、RGB 与同步信号配套 |
| `SD/sd_dual_audio.v`、`audio_output_mixer.v` | 读出 WAV 并与提示音混合 | 音频事件、采样缓冲和输出节拍 |
| `audio_spectrum_engine.v`、`audio_spectrum_overlay.v` | 根据音频生成频谱并叠加到画面 | 频段数据更新与像素区域判断 |
| `ui_settings_overlay.v` | 叠加参数面板并调整画面 | 参数输入、颜色处理及视频同步 |

先沿“按键→调度→资源管理”理解一笔请求如何准备图片，再沿“SDRAM→读控制器→FIFO→合成器”理解图片如何进入画面。顶层的实际例化和连线用于确认模块关系。

## 主要辅助模块

交互入口由 `guide_nav_buttons.v`、`direction_key_event.v` 和 `guide_key_control.v` 内的 `guide_button_debounce` 处理消抖与长短按。`map_navigation.v` 计算地图视野和观察点选择，`room_elapsed_store.v` 保存占用计时。

资源管理器通过 `SD/shared_fat32_reader.v` 共用读卡通路，`SD/fat32_named_file.v` 按文件名查找资源，`SD/bmp_dynamic_read.v` 解析图片，`SD/sd_wav_player.v` 解析音频。`held_bus_cdc.v` 用于跨时钟域传递保持型参数。

显示端先由 `SD/video_delay.v` 对齐 FIFO 像素和同步信号，再进入图文合成器。`scene_motion.v`、`room_list_scroll.v`、`room_list_fade.v` 和 `room_status_ticker.v` 提供相应区域的动画参数；名称与文字地址规则见 `guide_site_config.vh`，字模实现见 `guide_font_rom.v`、`guide_large_font.v`、`room_notes_font.v`。后置视口、频谱和设置面板完成处理后，由 `video_rgb_to_axis.v`、HDMI IP 及 PHY 输出。

## 排版与折叠

主要控制模块以 `// region 编号 名称` 和 `// endregion` 分区，通常依次为接口、参数与状态、组合判断、时序更新。支持这些标记的编辑器可按区折叠；其他编辑器可按模块、`always` 和 `begin/end` 结构浏览。注释中的握手条件以该文件当前实现为准，参数默认值与顶层实际传参需结合查看。

字模数据表、厂商 IP 和历史对照模块保留原文件。`floor_guide_compositor.v`、`image_motion_overlay.v` 等旧模块不属于当前主显示链路；阅读当前实现以 `top` 实际例化为准。
